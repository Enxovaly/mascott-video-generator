# Enxovaly Mascot Lab

For any request to create, animate, convert, or vary the Enxovaly mascot, read
and follow `.agents/skills/enxovaly-mascot/SKILL.md` before acting.

Use Codex image generation for still images. Never use OpenRouter for image
generation. Every new animation must be generated by Seedance through the
configured video provider; never substitute deterministic, procedural, sprite,
or transform-only motion. If Seedance is unavailable or unauthorized, stop and
report the blocker. Never print, commit, or persist `OPENROUTER_API_KEY`. Paid
video generation requires an explicit user request and the CLI `--yes` flag.

Treat `references/CHARACTER.md` as the source of truth for identity. Preserve
the canonical reference files unless the user explicitly approves a new
character master.
